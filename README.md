# AVIZ-CPU-32bit-RISCV
Ongoing personal project (Aug. 2026 - Present)
32-Bit CPU designed in SystemVerilog, with RISC-V architecture.

Eventually going to expand this for applications to showcase the advantages of FPGAs.
Originally had these files locally on my computer; I decided to host them on GitHub. 

As of October 3rd, 2026, I pushed 7 basic components to the repository; I am currently working to rework more files to push. 

Each arithmetic module is parameterized for variable width, allowing for scalability of hardware.
For example, the 'adder_nwidth.sv' module can be adjusted for an 8-bit, 16-bit, or 64-bit CPU.

The CPU example I am designing is 32-bits.
